# Layer 3 → 5/5 Plan

Goal: close every remaining Layer-3 finding so the next audit shows no HIGH and at most 2 MEDIUM items, with each fix protected by a test that fails in CI if it regresses.

Note: several fixes were already coded earlier in this session (free-enrollment routing, FLAG_SECURE breadcrumb, LiveClass safety kit, resume coalescing, postcss pin). This plan verifies those and adds the missing test/CI work that a real 5/5 requires.

## 1. HIGH — Free-course enrollment
- `BuyCourse.tsx` now calls the `self-enroll-free` edge function instead of a client-side `enrollments.upsert()`.
- Add an integration test: client writes to `enrollments` stay rejected; `self-enroll-free` enrolls a free course and is idempotent on a repeat call.
- Confirm a paid course id sent to `self-enroll-free` is rejected, so the price ceiling stays on the server.

## 2. MEDIUM — Resume recovery behavioral tests
Fake-timer suite for `useResumeRecovery` + `DocumentReader`:
- background → stuck-load window elapses while hidden → resume → no false error overlay.
- error already painted → resume → exactly one auto-retry, never a loop.
- duplicate `visibilitychange` + Capacitor `appStateChange` → one recovery pass, reload one-shot guard retained.
- stale background past the threshold → one reload, not two.
- `resumeEpoch` bump forces a PDF remount and the document renders again.

## 3. MEDIUM — FLAG_SECURE observability
- `useScreenProtection` now records a redacted warning when the native reconcile throws.
- Test: plugin whose `enable()` rejects → warning recorded, internal enabled state untouched so the next reconcile retries, and no student-facing alert.

## 4. MEDIUM — LiveClass safety kit
- LiveClass now uses `useProtectedSurface`, a mount-guarded session fetch, a layout skeleton, and `SafeBoundary`.
- Test: unmount during the pending fetch performs no setState; a throwing child renders the boundary fallback.

## 5. MEDIUM — PDF memory safeguards measured by behavior
- Replace constant-asserting tests with behavioral ones: distant pages actually release their canvas (mocked IntersectionObserver), DPR stays clamped at high zoom, aborted transport clears timers and network handles.

## 6. LOW — Android resume coverage in CI
- Add Maestro flows: open PDF → Home mid-load → return; `am send-trim-memory COMPLETE`; FLAG_SECURE reapplied after resume.
- Make the PDF and back-button supplemental flows blocking so a regression fails the workflow.

## 7. Dependency + build gate (bun-based, unchanged pipeline)
- postcss is pinned to 8.5.26 in `package.json` overrides/resolutions with both lockfiles regenerated; re-run the dependency scan to confirm 0 vulnerabilities.
- Ship check stays: `bun install` → `bun run build` → `npx cap sync android` → gradle debug assemble through the existing workflow. No action-version bumps, no `minifyEnabled` for debug, no daemon changes.

## Definition of 5/5
- No HIGH findings; free enrollment works end to end.
- Resume, FLAG_SECURE, LiveClass and PDF memory each have a regression test.
- Maestro resume flows blocking in CI.
- Dependency scan clean; typecheck and the full vitest suite green; APK builds via the existing bun pipeline.
